City Population and Temperature

A four-dimensional scatterplot comparing population, temperature, development level, and region across twelve cities.

Visualization

Population → x-position · Temperature → y-position · Development level → size · Region → color

Design Justification

Population is mapped to the horizontal position because it is a ratio variable with a meaningful zero, and a common linear axis makes city populations easy to compare. Average temperature is mapped to the vertical position because Celsius is an interval variable; position supports accurate comparison of both values and differences. Region is a nominal variable, so color separates North, South, East, and West without implying that one region is greater than another. Development level is ordinal and is represented by point size: Low, Medium, and High use progressively larger circles to communicate their natural order. Together, these mappings help viewers notice relationships between city size and climate while also revealing regional groups and development patterns. A tooltip identifies each city and provides its exact values, while separate color and size legends make all four encodings clear.
