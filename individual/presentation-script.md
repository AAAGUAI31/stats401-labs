# 1-minute presentation script

The original OECD Better Life Index uses flower glyphs to compare 38 countries across 11 dimensions. The design is memorable, but precise comparison is difficult. Petals point in different directions, so countries lack a shared baseline. Length shows performance, while width changes with user priorities. This mixes two meanings in one mark. Ranking one dimension also requires scanning hundreds of petals.

My redesign replaces the flowers with a sortable heatmap. Rows are countries, columns are well-being dimensions, and every cell uses the same zero-to-ten scale. Users can sort any dimension to find the highest and lowest countries immediately. The sliders affect only the weighted overall score, so the underlying data never changes visually. Clicking a country opens a horizontal dot plot on a common scale. The redesign loses some playfulness, but it makes comparison, ranking, and interpretation faster and clearer.
