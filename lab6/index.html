Design description

Both treemaps use rectangle area (size) to encode GDP because area supports a direct part-to-whole comparison within each region and continent. Country color represents GDP status: green indicates an increase, gray indicates no change, and red indicates a decrease. Using the same color mapping in both views makes status comparisons consistent, while tooltips provide exact GDP values and the full continent–area–country path. The Squarify layout produces compact rectangles with relatively balanced aspect ratios, making country labels and area comparisons easier to read. The Slice–Dice layout alternates horizontal and vertical partitions across hierarchy levels, so continent and regional groupings are visually clearer; however, it creates more narrow rectangles, which can make small countries harder to label （such as Oceania is clear in left side, but hard to read in the right side）. Showing both layouts demonstrates that identical hierarchical values can produce different spatial organizations and reading priorities.
