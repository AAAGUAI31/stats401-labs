Task 1 · 检查 SpeechRecognition

Task 4 · 映射到图表动作

handleVoiceCommand() 不直接画图，只调用共享的可视化函数。

查看 Task 1–4 的最小核心代码 
const SpeechRecognition =
    window.SpeechRecognition || window.webkitSpeechRecognition;

// Task 2：必须由用户点击后启动，不能自动打开麦克风。
voiceButton.addEventListener("click", () => recognition.start());

// Task 3：把声音识别成规范化文本。
recognition.onresult = (event) => {
    const command = event.results[0][0].transcript.toLowerCase().trim();
    handleVoiceCommand(command);
};

// Task 4：输入层只负责调用可视化层的函数。
function handleVoiceCommand(command) {
    if (command.includes("reset")) resetVisualization();
    else if (command.includes("show asia")) filterRegion("Asia");
}

查看 Task 9–10 的最小核心代码 
let lastGestureTime = 0;
const GESTURE_COOLDOWN = 1000;

function triggerGesture(gesture) {
    const now = Date.now();

    // Task 10：一秒内只允许一次可视化命令。
    if (now - lastGestureTime < GESTURE_COOLDOWN) return;

    lastGestureTime = now;
    handleGesture(gesture);
}

function handleGesture(gesture) {
    if (gesture === "Open_Palm") resetVisualization();
    else if (gesture === "Swipe_Right") moveTimeStep(1);
    else if (gesture === "Swipe_Left") moveTimeStep(-1);
}

function gazeListener(data) {

运行说明与隐私边界

  1. 在仓库根目录运行 python -m http.server 8000。
  2. 浏览器打开 http://localhost:8000/lab10/task1-13-demo.html。
  3. 语音建议使用 Chrome 或 Edge；摄像头功能需要 localhost 或 HTTPS。
  4. D3、MediaPipe 模型和 WebGazer-compatible 引擎由 CDN 加载，因此首次运行需要联网。
  5. 页面只在点击对应启动按钮后请求麦克风/摄像头；停止按钮会关闭媒体流。
教学依赖： MediaPipe Gesture Recognizer · WebGazer.js · WebGazer TS compatibility engine
